# 藥品調撥分析本機試作

在專案根目錄執行：

```sh
python3 site-preview/server.py
```

開啟 http://127.0.0.1:8765 。伺服器僅提供靜態檔案及根目錄既有的
`stock_transfer.db`，不執行資料匯入或修改資料庫。替換資料庫後重新整理即可。
查詢與計算在瀏覽器的 Web Worker 內使用 sql.js 1.17.0 執行，無外部 CDN 請求。

## 計算規則

- 先以起訖月份（含首尾）、品項及每筆月結算調藥次數共同篩選紀錄。
- 次數上下限可輸入 1–50，預設下限 1、上限 10；不以跨月加總值排除品項。
- 起始月份與結束月份皆預設為最新已匯入月份，仍可手動調整月份區間。
- 「重設」直接重新載入首頁，恢復最新月份、全部品項、每月 1–10 次，以及初始圖表、明細排序與分頁；一併清除搜尋、錯誤與查詢狀態，不必再按「套用條件」。
- 圓餅分母是全部篩選條件套用後，剩餘的月結算紀錄總筆數。
- 依每筆月結算調藥次數分為 1、2、3、4、5 次，各類占比＝該類筆數／篩選後總筆數，不以調藥次數加權。
- 「其他」只包含篩選後每月超過 5 次的紀錄，被排除資料不進入任何分類或分母。
- 圖例按次數分類排序；點選分類只顯示該類月結算紀錄。明細與圖表使用相同資料集合。
- 無符合紀錄時，總次數為 0，不產生「其他 100%」的假象。
- 從 import_history 取得已匯入月份；未收錄紀錄不補零。

本目錄尚未建立 Sites 專案或發布。未來靜態上架時，需將公開資料庫作為
`stock_transfer.db` 隨靜態檔案一同打包；`server.py` 不屬於部署內容。

`vendor/` 為 sql.js 1.17.0 的瀏覽器檔案及 MIT 授權。

## Excel 匯出

明細頁的「下載 Excel」會匯出當前篩選、分類及排序下的完整資料，不受分頁限制。
活頁簿只保留「月別調藥明細」一頁；數值保持數字，代碼保持文字。
ExcelJS 4.4.0 在瀏覽器產生 XLSX，`vendor/EXCELJS-LICENSE` 保存其 MIT 授權。

本機版提供桌面、下載項目或自訂現有資料夾，儲存成功後顯示完整路徑。
同名檔案預設自動加編號；勾選「取代同名檔案」才會以原路徑及檔名儲存。
API 僅允許同源本機頁面儲存 XLSX。
未來純靜態 Sites 版本使用原生檔案儲存 API（支援時）或瀏覽器下載；
純靜態瀏覽器模式無法取得完整資料夾路徑，介面會如實提示。
